## Overview

CryptoBot is a TypeScript-based automated trading bot deployed on a VPS and managed via [pm2](https://pm2.keymetrics.io/). It runs 24/7 on a remote server at `178.156.149.251`.

## Infrastructure

| Resource | Value |
|---|---|
| VPS IP | `178.156.149.251` |
| VPS codebase | `/opt/cryptobot/` |
| Local mirror | `~/Documents/_cryptobot_vps/` |
| Process manager | pm2 — process name `cryptobot` |
| Log file | `/root/.pm2/logs/cryptobot-out.log` |

## Tech stack

- **Runtime**: Node.js (TypeScript compiled to `dist/`)
- **Process manager**: pm2
- **Deployment**: custom `deploy.sh` script (rsync + compile)
- **SSH access**: `root@178.156.149.251`
