## 1. SSH into the VPS

```bash
ssh root@178.156.149.251
```

If this is your first connection, accept the host fingerprint prompt.

## 2. Check bot status

```bash
pm2 logs cryptobot --lines 50 --nostream
```

You should see recent log output from the bot. A healthy bot will show continuous activity lines rather than crash-restart cycles.

## 3. Verify pm2 process list

```bash
pm2 list
```

The `cryptobot` process should show status **online** and a low restart count.

## 4. Tail live logs

```bash
pm2 logs cryptobot
```

Press `Ctrl+C` to exit. The log file is also available at:

```
/root/.pm2/logs/cryptobot-out.log
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Process is stopped or errored">
    Restart the bot and check logs immediately for the crash reason:

    ```bash
    pm2 restart cryptobot --update-env
    pm2 logs cryptobot --lines 100 --nostream
    ```
  </Accordion>
  <Accordion title="High restart count">
    The bot is crash-looping. Check error logs:

    ```bash
    cat /root/.pm2/logs/cryptobot-error.log | tail -50
    ```
  </Accordion>
  <Accordion title="Cannot SSH into VPS">
    Verify your SSH key is added and the server is reachable:

    ```bash
    ping 178.156.149.251
    ```
  </Accordion>
</AccordionGroup>
